# 遊びの棚

公開サイト：https://maru0720.github.io/asobi-no-tana/

## 掲載ゲーム
- キッズＧＯサバイバー：2026-11-21に更新版を変換。プレイ中は方向キー、強化画面はマウスで操作します。
- 奥行回避ゲーム：左右キーで操作する新作。サムネイルにはゲーム内背景を使用。生成AIは使用していません。

Scratchゲームをブラウザで遊べるようにするサイトです。現在はSTEP 3で、一覧から専用ページへ移動してゲームを遊べる構造を作成しました。

## 確認方法
1. VS Codeでこのscratch-game-siteフォルダーを開きます。
2. エクスプローラーでindex.htmlをダブルクリックします。既に開いている場合はブラウザを再読み込みします。
3. 「ゲームで遊ぶ」をクリックし、専用ページにゲームが表示されることを確認します。
4. 緑の旗で開始します。プレイ中は方向キーで移動し、強化画面ではマウスで選択します。
5. 「ゲーム一覧に戻る」で一覧へ戻れることを確認します。ページを離れるとプレイは終了します。

追加インストールは不要です。ブラウザでの表示確認はユーザーと行います。

## ファイル構成
- index.html：ページの構造とゲーム紹介。
- play-survivor.html：ゲームの専用ページと一覧に戻るリンク。
- css/style.css：色、余白、カードの配置。
- js/main.js：今後の動作の置き場。STEP 1の確認処理は役目を終えたため削除しています。
- assets/images/：サムネイル用。
- assets/images/survivor-title.png：sb3の「OP背景」から取り出したタイトル画像。一覧のサムネイルとして使用。
- games/：ゲーム本体と編集用の元作品。
- games/survivor.html：TurboWarp Packagerで生成したゲーム。ブラウザで直接開いて起動確認できます。
- games/キッズＧＯサバイバー.sb3：編集用の元作品。変換後も残しています。
- AGENTS.md：開発ルールと決定事項。

空フォルダーの.gitkeepは、Gitで置き場を残すための空ファイルです。

## STEP 2の学習ポイント
- article：ゲーム紹介など独立した内容をまとめるHTML要素。
- class：CSSで見た目を指定するためにHTMLへ付ける名前。
- CSS Grid：カードを行や列に並べる仕組み。
- 相対パス：現在のファイルを基準とする道順。./css/style.cssでCSSを読み込みます。

一覧をHTMLに直接書く方法は読みやすい反面、作品が増えると同じ構造の編集が増えます。JavaScriptでデータから作る方法は追加をまとめやすい反面、学ぶ仕組みが増えるため、必要になった段階で検討します。

## STEP 3の進捗
ゲームを標準設定でHTMLに変換し、一覧と専用ページを接続しました。ユーザーが埋め込みページでプレイできることを確認済みです。一覧に戻るリンクの動作確認は残っています。
ゲームのHTMLは生成物なので、ゲーム自体を修正する場合は元のsb3を編集して再変換します。

iframeは、別のHTMLをページ内に表示する枠です。専用ページの中にゲームHTMLを表示することで、ゲーム本体を編集せずに「一覧に戻る」リンクを設置できます。

当面は制作者本人だけがゲームを追加します。管理画面からのアップロード・変換・公開は将来の機能で、まだ実装していません。
